# zirkonyx-prueba-1
Prueba de ZIRKONYX: página creada desde cero (fotografía)

Página de una sola página de **Lumbre Fotografía** (Lucía, fotógrafa de bodas en Manizales).
Es un sitio estático: no necesita instalar nada ni compilar.

## Estructura

- `index.html` — la página: barra superior, portada dividida, galería, «Quién soy y cómo trabajo», franja dorada de contacto y pie.
- `css/styles.css` — estilos. Los colores están como variables al inicio (`--dorado`, `--crema`, etc.).
- `img/` — fotos de la página.

## Cómo verla

Abrir `index.html` en el navegador. Para publicarla, subir la carpeta completa (`index.html`, `css/` e `img/`) a cualquier hosting estático (por ejemplo GitHub Pages, Netlify o Vercel).

## Contenido de ejemplo por reemplazar

- **Fotos**: las de `img/` son de ejemplo, creadas con IA. Para cambiarlas basta reemplazar el archivo conservando el nombre:
  - `img/portada-pareja-montanas.jpg` — foto de la portada y una celda de la galería.
  - `img/ceremonia-arco-flores.jpg` — foto protagonista de la galería y otra celda.
  - `img/anillos-ramo.jpg` — dos celdas de la galería.
  Conviene que cada foto pese menos de 400 KB para que la página cargue rápido en celular.
- **Texto «Quién soy y cómo trabajo»**: en `index.html`, marcado con el comentario `TEXTO DE EJEMPLO`.
